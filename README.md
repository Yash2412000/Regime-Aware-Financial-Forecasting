## Overview

Financial markets are dynamic systems where relationships between variables
change over time due to economic conditions, investor behaviour, and unexpected
events. Traditional forecasting approaches often rely on fixed assumptions and
single forecasting models, limiting their ability to adapt to changing market
conditions.

This project implements a **regime-aware, explainable multi-modal financial
forecasting framework** based on a **Mixture of Experts (MoE)** architecture.

The framework combines multiple forecasting experts and dynamically adjusts
their contribution based on detected market regimes. Explainable Artificial
Intelligence (XAI) techniques are integrated to understand model decisions and
feature influence.

# Key Features

## 1. Multi-Modal Financial Representation

The framework incorporates multiple financial information sources:

- Historical market data
- Technical indicators
- Financial sentiment information
- Macroeconomic context

These different sources are processed and combined to create a richer market
representation.

---

## 2. Market Regime Detection

A Hidden Markov Model (HMM) is used to identify different financial market
conditions.

Detected regimes:

- Bull market
- Bear market
- High volatility market

The detected regime information is provided to the gating network to enable
adaptive forecasting.

---

## 3. Mixture of Experts Forecasting

Instead of relying on a single forecasting model, the framework uses multiple
specialised forecasting experts:

| Expert | Purpose |
|---|---|
| LSTM | Captures sequential temporal patterns |
| GRU | Learns historical dependencies efficiently |
| Transformer | Captures long-range relationships using attention |
| Linear Model | Provides a simple interpretable forecasting baseline |

The final prediction is generated by combining expert outputs using dynamically
learned weights.

---

## 4. Adaptive Gating Network

The gating network determines the contribution of each expert depending on the
current market regime.

This enables:

- Dynamic expert selection
- Adaptation to changing market behaviour
- Avoidance of fixed forecasting strategies

---

# Explainability

Deep learning forecasting models are often considered black-box systems.

This project applies **SHAP (SHapley Additive exPlanations)** analysis to
interpret:

- Factors influencing expert selection
- Feature importance under different market regimes
- Individual expert prediction behaviour

The explainability module provides insights into how forecasting decisions are
generated.

# Training the Model

Run:

```bash
python src/train.py --epochs 30
```

The training pipeline performs:

1. Financial data loading
2. Feature preparation
3. Market regime detection using HMM
4. Mixture of Experts training
5. Model validation
6. Test prediction generation

# Model Evaluation

# Experimental Results

Final test performance:

| Model | MAE | RMSE | Directional Accuracy |
|---|---:|---:|---:|
| ARIMA | 0.02271 | 0.03204 | 51.68% |
| Ensemble Average | 0.02410 | 0.03336 | 51.81% |
| Single LSTM | 0.02228 | 0.03175 | 58.36% |
| Proposed MoE Framework | 0.02228 | 0.03178 | 58.20% |

The proposed framework achieved competitive forecasting performance while
providing adaptive expert selection and improved interpretability.
